## Ubuntu 适配与 Windows 服务保留（2026-10-27）

服务打包已与 Electron 解耦：独立构建输出 Ubuntu tar.gz 及校验和、Windows 服务目录和旧通用服务路径。Ubuntu 安装器提供版本化程序、固定凭据、独立持久数据、系统账号、systemd 开机启动/异常重启及带鉴权就绪检查；不自动覆盖现有 HTTPS 配置、云安全组或业务空间。Windows 的 Node 启动及恢复脚本继续提供。

平台专项验收：Ubuntu 22.04.5 LTS x86_64（WSL）使用官方 Linux Node 22.23.4，发行包完整性、实际启动/鉴权/同步/重启/导出恢复/重复实例拒绝，以及 Shell 预检与 systemd 静态校验共 3/3 通过，日志 `.build/ubuntu-server-check.log`。Windows 原生专项使用实际 start-server.cmd，2/2 通过，Linux 专项 1 项在 Windows 上按平台跳过，日志 `.build/server-deployment-check.log`。Windows 桌面及独立服务/MCP 分发仍由 release.test.mjs 回归。测试不会读取用户既有数据；未修改 WSL 的系统配置或启用其 systemd。

WSL 的 PID 1 不是 systemd，因此 systemd 的实际开机运行、阿里云云主机、域名和公网 TLS 尚需在目标环境核验；没有将静态 unit 验证描述为云部署成功。arm64 下载和启动材料已提供，未作为已运行硬件记录。
