## 交付材料

| 材料 | 位置 | 使用方式 |
|---|---|---|
| Windows 便携客户端 | `.build/release/workspace-windows-v0.1.0/工作空间.exe` | 保留整个目录并直接运行，无需开发依赖 |
| 独立 Node 服务 | `.build/release/workspace-server-v0.1.0/` | 设置数据目录及所有者凭据后启动，见使用指南 |
| 导出/恢复命令行 | 随包 `scripts/archive-cli.mjs` | 预览、恢复及本机材料准备权威目标 |
| MCP stdio 服务 | 随包 `apps/mcp/protocol/main.mjs` | 外部客户端按具名授权连接 |
| 独立扩展样例 | 随包扩展样例与仓库 `extensions/` | 显式注册/补齐兼容材料 |
| 使用指南 | [使用指南](使用指南.md) | 启动、同步、扩展、导出恢复、迁移及 MCP |

程序与数据目录分离。Windows 交付为便携目录，无安装向导、签名或自动更新；其他平台没有被列为已测试原生客户端。
