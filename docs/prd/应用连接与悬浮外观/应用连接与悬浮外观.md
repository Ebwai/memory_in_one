# 应用连接与悬浮外观

## 功能与定位

应用连接与悬浮外观 [C] 包含内置 SSH 连接 [C] ● 和圆角悬浮窗口 [C] ●。

## 业务规则与交互

用户在初始页或工作空间管理选择私钥，填写服务器、SSH 用户名、端口和可信主机指纹，保存启用自动连接。之后打开应用自动连接，网络断开后重试，手动断开后停止自动连接。私钥只在当前设备保存，不上传。身份错误、指纹不符和本地端口冲突明确显示失败，不关闭外部通道，不把通道建立等同于业务数据已同步。

悬浮待办使用参考图的大圆角白色表面和轻外阴影；自定义顶部拖动区域提供最小化、关闭，原有置顶与管理入口保留。关闭复用原草稿保护，不直接丢弃输入。

## 前置与边界

复用已有工作空间接入、离线保存、同步和窗口草稿保护。Windows 需要 OpenSSH 客户端；首版面向私钥无需交互口令的连接。私钥有口令时提示身份连接失败，不在后台弹出密码终端。原 PowerShell 通道占用本机端口时先由用户关闭原通道再启用内置连接。
