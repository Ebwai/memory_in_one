# 多端记录与持续推进 [C]

状态：通用产品方向已确认；2026-10-26 已完成 N42 整体验收，接续同一内容的收录、回看和推进。

## 功能描述

让用户在碎片时间留下内容，并在有时间时找回、继续思考和推进；不同设备围绕同一份内容及当前进度工作。


## 业务规则与约束

来自用户的已知要求：记录应快速；后续推进建立在已有内容之上；不让不同设备上的独立副本造成进度分裂。首个落地方向为 Windows 待办。

三个通用概念各自描述记录、回看和推进，并引用公共机制区的统一进度保障；共享机制不由本分支独占。内容推进后再次回看应能接续已有成果。领域映射表示具体业务落点，机制引用表示共同依赖，不重复定义规则。

## 交互流程和细节

用户产生想法 → 留下内容 → 有空时集中找回 → 继续处理 → 后续访问可接续已有成果。具体入口、反馈及失败行为待下层展开。

## 数据范围

用户记录的内容及其推进结果。具体内容类型由“信息领域管理”定义。

## 前置能力

本节点三个通用概念共享统一进度保障。信息领域管理定义领域归属，数据自主与迁移处理部署迁移与恢复；具体产品依赖随拆解确定。通用概念到 todo-list 的链接是领域落点映射，不将 todo-list 当作所有领域的必需前置。

## 边界情况与异常处理

离线记录、同时修改和暂时无法访问统一位置时的现有产品规则已在统一进度保障子树确认，包括本机保存、状态反馈、重启接续、自动同步与冲突选择；具体技术实现和阶段交付范围尚未确定。

## 后续已知输入

后续只在本节点细化跨领域共享能力，具体领域规则在对应领域子树维护。
