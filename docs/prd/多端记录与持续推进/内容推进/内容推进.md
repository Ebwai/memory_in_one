# 内容推进 [C]

状态：通用能力分类已于 2026-10-24 确认；2026-10-25 按用户要求将待办专属规则归入 todo-list。本节点非原子节点，未新增写操作规则。

## 功能描述

让用户基于已有内容继续思考、补充信息和推进进度，而不反复产生互不关联的成果。

## 定位

```text
多端记录与持续推进
└── 内容推进 [C]
    ⇢ 领域落点：[[../../信息领域管理/todo-list/待办推进/待办推进.md|待办推进]]
```

此处为领域映射引用，不是层级子节点。勾选完成、截止日期和待办删除规则由 todo-list 定义。

## 业务规则与约束

后续处理应基于同一份内容的已有成果。具体可执行动作由所属领域决定，不要求项目想法等其他内容也具有待办完成状态。

## 交互流程和细节

用户选中已有内容 → 按领域方式继续处理 → 获得更新结果 → 后续可接续成果。待办的修改、日期、完成和删除见待办推进。

## 数据范围

已有内容、附加信息及其推进结果；不在本节点定义各领域的状态字段。

## 前置能力

引用 [统一进度保障](../../公共机制/统一进度保障/统一进度保障.md)。待办推进是具体领域落点，不与本通用能力形成相互前置依赖。

## 边界情况与异常处理

并发修改、离线和更新结果不明的共享语义待统一进度保障细化；待办取消编辑、撤回完成、删除确认等既有已确认规则留在对应领域。
