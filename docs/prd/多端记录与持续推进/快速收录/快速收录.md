# 快速收录 [C]

状态：通用能力分类已于 2026-10-24 确认；2026-10-25 按用户要求将待办专属规则归入 todo-list。本节点非原子节点，未新增具体收录规则。

实现状态（2026-10-25）：N15 已完成当前 Windows 本机快速收录映射整合，并以独立阅读摘录扩展验证领域隔离；不将待办字段强加给其他领域，也不宣称其他设备入口或联网同步已完成。

## 功能描述

让用户在碎片时间用手边设备留下新内容，之后可以找回并继续推进。通用能力不规定所有信息领域必须使用待办的字段或界面。

## 定位

```text
多端记录与持续推进
└── 快速收录 [C]
    ⇢ 领域落点：[[../../信息领域管理/todo-list/待办快速收录/待办快速收录.md|待办快速收录]]
```

此处为领域映射引用，不是层级子节点或互相依赖。待办专属节点仅在 todo-list 子树展开。

## 业务规则与约束

已确认的产品方向：先留下再整理，避免整理负担阻止记录。各领域的最低输入、入口、校验和提交规则由该领域定义。

## 交互流程和细节

用户进入适用领域的记录入口 → 留下新内容 → 获得可理解的提交结果 → 后续可回看、推进。Windows 悬浮窗口等具体交互见待办领域。

## 数据范围

各信息领域新录入的内容；不在本节点规定统一待办字段。

## 前置能力

引用 [统一进度保障](../../公共机制/统一进度保障/统一进度保障.md)。领域映射不表示本通用能力依赖 todo-list 才能成立。

## 边界情况与异常处理

可靠保存、离线与结果不明的通用语义待统一进度保障细化；已确认的待办失败反馈由待办快速收录保有，不提升为其他领域的强制交互。
