# 更新安装与接续

## 功能描述与定位

桌面应用更新的原子概念：用户一键下载选定新版，经校验、正常退出和替换后继续使用同一工作空间。

## 业务规则与约束

先完成下载与完整性核验，再退出旧版。复用既有草稿退出保护；不把未提交输入当成已保存成果。安装互斥，不覆盖数据、绑定、凭据或未同步材料，不修改远端服务。

## 交互流程和细节

正式版本发现提供目标后，用户点击“一键更新”，观察下载进度；准备完成后处理未保存输入并安装重启。取消退出时保留准备结果，可点击“安装并重启”。新版正常启动后继续使用原空间。

## 前置能力

正式版本发现、领域退出草稿保护、程序与持久数据分离。

## 边界与异常

下载中断、材料损坏或目录不可写时不替换旧程序；替换或启动失败时尝试恢复旧版。源码运行不自动安装；旧版首次获得此能力需要手动换装。
