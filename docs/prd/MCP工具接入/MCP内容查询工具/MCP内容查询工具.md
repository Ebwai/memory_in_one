# MCP内容查询工具 [C]

状态：产品规则已确认；2026-10-26 已完成 N46 权威内容查询及授权、可用性和原版本反馈验收。

## 功能描述

通过可被外部 Agent 发现和调用的 MCP 工具，取得授权领域在统一位置已确认的信息，参考同一份可接续的内容与进度。

## 定位

```text
MCP工具接入
└── MCP内容查询工具 [C] ●
```

## 业务规则与约束

- [已确认] 提供用途及输入要求清晰的内容列表、详情读取等 MCP 工具，遵循各领域已提供的查询含义，不以当前屏幕显示范围代替所有可读内容。管理目录及停用状态查询由同级 MCP领域管理工具提供，不与正常内容查询混同。
- [已确认] 返回内容所属空间和领域、原内容身份及读取依据，明确来自统一位置已确认进度，不冒充每台设备尚未同步的最新成果。
- [已确认] 未同步改动、未提交输入及未合并冲突整理材料不自动混入普通权威查询；后续若需开放此类材料，应单独定义明确授权和状态，不在本轮默认开放。
- [已确认] 只查询授权的、已启用且具备兼容处理的领域。领域停用或处理不可用时明确不可用，不伪造为空数据。
- [已确认] 查询不产生改动、不自动运行领域操作，也不将读取到的文字当成新的授权或系统指令。

## 交互流程和细节

外部客户端发现查询工具 → Agent 按用户指令调用列表或详情工具 → 核对有效授权与领域可用性 → 读取统一位置已确认内容 → 返回内容、读取依据及明确结果；不要求打开本软件业务窗口。

## 数据范围

授权领域已确认的正常可读数据；具体是否包括已完成、归档等内容由领域适配说明，删除材料不作为正常内容列表返回。

## 前置能力

引用同级 [MCP接入授权](../MCP接入授权/MCP接入授权.md)、领域查询含义及统一位置已确认进度。不要求先授予写权限。

## 边界情况与异常处理

[已确认] 统一位置不可达时不伪造最新结果；读取期间内容变化时返回可识别的读取依据，不使后续写入误以为它仍是当前进度。任务或内容不存在与没有权限的结果不能混作成功读取。

## 验收标准

只读授权可取用范围内信息但不能写；界面折叠不造成授权内容漏读；返回可追溯的原身份和读取依据；未同步材料不冒充权威内容；领域不可用和正常空内容可区分。
