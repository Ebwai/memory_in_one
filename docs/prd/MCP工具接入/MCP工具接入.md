# MCP工具接入 [C]

状态：产品规则已确认；2026-10-26 已完成 N49 整合，真实外部 stdio MCP 客户端验证发现、调用、确认及撤销。具名 Codex／Claude Code 客户端及语音体验未作实测声明。

## 功能描述

本软件作为 MCP 工具服务，向外部 Agent 提供发现、查询和操作工作空间各领域的能力。外部 Agent 负责理解用户指令、选择和编排工具，本软件负责执行领域动作并返回明确结果。

用户可通过外部客户端的文字或语音入口发号施令。语音输入、语言理解和 Agent 循环由外部接入端承担；本项目交付 MCP 工具服务及领域能力，不开发内置 Agent 或语音识别引擎。Codex、Claude Code 是用户指出的接入对象，具体兼容性在实施阶段验证。

## 业务规则与约束

- [用户明确] 对外接入方式为 MCP，提供外部 Agent 所需工具，使其能够像人工使用业务界面一样操作领域；本软件不承担 Agent 的理解、推理或自主编排。
- [用户明确] 各信息领域共享一个统一工具入口；todo-list 的专属工具和数据含义归于其领域子树。新增领域按自身能力接入，不自动变成待办，也不要求每个领域另起一个独立信息来源。
- [已确认] 工具覆盖领域目录及状态查询、领域注册和启停等管理动作，以及各领域已存在的内容查询与业务动作。所有工具复用人工界面所用的领域规则、保存、同步和冲突机制，不另建 Agent 专用副本。
- [已确认] 外部客户端能够发现当前可用工具，取得清晰的用途、输入要求和明确的调用结果；新增或停用领域后可重新发现当前能力。工具不依赖本软件的窗口焦点或模拟鼠标点击。
- [已确认] 用户创建可撤销的接入授权，默认只读，按空间、领域和动作明确开放写权限。内容权限与领域管理权限区分，管理权限也不自动扩展为服务器迁移或恢复权限。
- [已确认] 需要用户确认的动作，通过工具返回待确认对象和操作信息，在外部客户端完成用户确认后继续；可经文字或语音交互，不强制用户切回本软件图形界面。具体确认凭据与兼容方式由架构和 TDD 定义，不把 Agent 自述当作用户确认。

## 交互流程和细节

```text
用户文字或语音指令
→ 外部客户端／Agent 理解并选择工具
→ MCP 工具服务校验接入、动作及当前进度
→ 调用既有领域能力
→ 保存结果并返回状态
→ 外部 Agent 向用户反馈
```

以待办为例，外部 Agent 可在授权后查询任务、添加任务、设置截止日期、完成或恢复任务；删除仍遵循已确认的具体对象确认原则，确认可在外部客户端承接。领域级动作也通过明确工具范围开放，不能只提供读取能力而缺少实际操作能力。

## 数据范围

工作空间领域登记、授权可读的已确认内容、领域动作及调用记录。普通权威查询不混入未知设备尚未同步的成果；访问本机未同步材料或冲突材料的额外工具仍需明确范围，不能冒充已确认内容。

## 前置能力

复用工作空间接入、领域登记与动作声明、已有保存和同步冲突规则。MCP 是这些能力的对外入口；外部 Agent 与人类界面共同接续同一份数据。每个领域声明自身工具含义，统一服务负责暴露与执行，不在此重写其业务规则。

## 边界情况与异常处理

[已确认] 无权限、领域不可用、参数无效、当前进度已变化、结果不明和服务不可达时，返回明确状态，不能误报成功。重复工具调用沿原操作核对和重试；外部客户端不具备某种交互能力时明确说明或使用兼容的确认路径，不静默执行本来需要用户确认的动作。

## 验收方向

接入一个真实外部 MCP 客户端后，可发现工具并在没有点击本软件业务界面的情况下查询和执行授权领域动作；能接续同一数据、处理重试和冲突，并将结果回传客户端。语音端到端体验取决于外部客户端是否具备相应输入能力，不假设所有客户端都自带语音。
