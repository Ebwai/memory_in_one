# MCP内容操作工具 [C]

状态：产品规则已确认；2026-10-26 已完成 N47 领域业务动作、原调用重试、并发保护、逐次删除确认及来源记录验收。

## 功能描述

向外部 Agent 暴露已有领域的内容操作 MCP 工具，执行其按用户指令发起的动作，推进同一份信息。外部 Agent 负责理解和选择工具，本服务负责校验和执行。

## 定位

```text
MCP工具接入
└── MCP内容操作工具 [C] ●
```

## 业务规则与约束

- [已确认] 领域声明的业务动作映射为用途、输入与结果明确的可发现 MCP 工具，只执行已授予且当前可用的动作。工具与人工界面使用同一领域能力，不另写一套业务规则，也不以模拟点击窗口代替领域操作；具体工具名与参数契约在 TDD 定义。
- [已确认] 针对同一内容的操作以读取到的进度为依据，当前已变化时沿既有并发判定和冲突规则处理，不强行覆盖。待用户处理的冲突不因调用者是 Agent 就自动选边。
- [已确认] 同一次请求重试保持原操作，不重复新增或反复切换状态；用户与 Agent 使用同一内容身份，不另建 Agent 专用副本。
- [已确认] 本轮通过统一位置接入执行；只有明确确认该位置已接受改动才向 Agent 返回写入成功。不可达或结果不明时明确反馈并接续核对，不把它冒充已完成的离线写入。
- [已确认] 删除等需要用户明确确认的动作，通过 MCP 返回具体对象与操作信息，由外部客户端承接用户文字或语音确认后继续，无需强制切回本软件图形界面。范围授权不替代具体对象确认，确认前有新进度需重新核对；具体确认承接方式由架构与 TDD 确定。
- [已确认] 写操作与来源和结果一起可追溯；未能可靠留下操作结果时不能报成功，也不能因记录反馈失败而盲目重新执行内容操作。
- 领域目录、注册、启停及本机程序管理由同级 MCP领域管理工具提供并单独授权；服务器迁移和备份恢复不因内容工具授权自动开放。

## 交互流程和细节

用户文字或语音指令 → 外部 Agent 基于查询结果调用内容工具 → 核对有效授权、领域规则和当前进度 → 必要时通过客户端承接用户确认 → 执行动作并保留调用记录 → 返回明确结果，由外部 Agent 向用户反馈。重试和结果核对复用共享规则。

## 数据范围

授权领域已有内容、创建动作及其操作结果和记录；具体待办动作只在 todo-list 的适用映射定义。

## 前置能力

引用同级 MCP接入授权、MCP内容查询工具的读取依据及 MCP调用记录；复用具体领域动作与共享可靠保存、重复操作、同步及冲突规则。

## 边界情况与异常处理

[已确认] 授权撤销、领域停用、目标已删除或进度变化时明确失败或冲突，不擅自改为新增。等待用户确认期间可取消，确认尚未发生不能提前执行；原操作结果不明时先核对，不换一次新请求来掩盖不确定结果。

## 验收标准

仅获授权动作可执行；重试不重复；人工并发不被覆盖；具体对象删除需用户确认；成功结果与来源记录一致；统一位置不可达不伪报成功；Agent 与人工接续同一份内容。
