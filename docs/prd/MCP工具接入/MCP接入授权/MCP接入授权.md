# MCP接入授权 [C]

状态：产品规则已确认；2026-10-26 已完成 N45 默认只读、范围授权、撤销及可靠变更记录。恢复后旧凭据不生效仍须在恢复节点验收。

## 功能描述

让用户明确授予外部 MCP 客户端或 Agent 对某工作空间、领域及工具动作的访问，并可随时停止后续访问。授权服务于本软件的 MCP 入口，不承担 Agent 执行编排。

## 定位

```text
MCP工具接入
└── MCP接入授权 [C] ●
```

## 业务规则与约束

- [已确认] 默认没有外部 AI 可访问的授权；用户创建具名接入授权，选择空间与可用领域，新增授权默认只读，写动作逐项明确授予。
- [已确认] 每次工具调用核对当前授权范围，Agent 自述、领域文字或同名来源不能扩大权限；内容查询与写入权限、领域注册启停和程序管理权限分别明确，内容授权不自动开放管理动作。服务器迁移和数据恢复权限也不随领域管理权限自动开放。
- [已确认] 用户可查看和撤销授权，撤销后拒绝后续请求及尚未执行的动作；先前已经确认的改动不因撤销自动回滚，已提交但结果不明的动作仍可由用户核对。
- [已确认] 当前范围授权不替代领域已有的具体对象确认；需要确认时通过 MCP 返回待确认信息，由外部客户端以文字或语音承接用户确认，不限定只能点击本软件窗口。确认须与对象、动作及当前进度关联，不能仅以 Agent 自述已获同意为依据。停用领域的内容操作不能借授权绕过限制，但单独获准的启用工具仍可使用。
- [已确认] 授权定义可随数据导出恢复作为参考，但恢复后旧访问凭据不自动重新有效；需由用户在当前环境重新明确接入授权。
- 用户已明确接入协议为 MCP；凭据、传输方式、确认承接与兼容协议版本留给技术设计。本软件不选择或运行外部 Agent 使用的模型。

## 交互流程和细节

用户进入 MCP 接入管理 → 创建名称、选择领域及内容或管理动作 → 明确授予 → 将接入配置用于外部客户端 → 外部 Agent 发现并调用授权工具。用户可撤销，后续调用按最新授权判定。

## 数据范围

接入名称、所属空间、领域与动作范围、有效或撤销状态，以及授权变更记录。访问凭据不写入普通操作记录。

## 前置能力

需要工作空间接入、领域可用性及同级操作记录留存能力；不以 Agent 已执行过操作为创建授权的前提。

## 边界情况与异常处理

[已确认] 授予或撤销失败不伪报完成；结果不明先核对。写入执行前需仍有有效授权，不能在用户已经撤销后凭旧请求继续执行。连接失败不自动授予更大范围。

## 验收标准

未授权不能访问；新授权只读；可限定领域与动作；撤销后的新操作被拒绝；已有内容正文不能扩权；恢复不自动恢复旧凭据效力；逐次删除确认不被范围授权替代。
