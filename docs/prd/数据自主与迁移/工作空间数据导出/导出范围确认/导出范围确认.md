# 导出范围确认 [C]

状态：产品规则已确认；2026-10-26 已完成 N50 双来源范围展示与确认，快照和文件生成已在后续 N51–N53 接续完成。

## 功能描述

让用户明确本次从哪里导出、包含什么、哪些尚未同步内容不在该来源持有范围内，避免把文件误认为包含所有设备的最新成果。

## 定位

```text
工作空间数据导出
└── 导出范围确认 [C] ●
```

## 业务规则与约束

- [已确认] 可选择“统一位置导出”或“本机可恢复数据导出”；发起前展示空间名称与身份、数据来源、已持有领域以及待同步或冲突状态。
- [已确认] 统一位置导出覆盖该位置持有的全部领域数据与恢复必要信息；其他设备还未上传的内容不声称已包含。
- [已确认] 本机导出覆盖本机可靠保存的领域数据、已取得的统一进度、本机未同步操作及冲突材料。可以离线执行，明确标注本机来源，不声称是统一位置最新全量状态。
- [已确认] 每种来源均覆盖其持有的全部已登记领域及配置、内容与身份、当前进度和必要删除接续信息；领域停用或程序缺失不构成静默略过数据的理由。
- [已确认] 只包含已可靠保存的内容。普通未提交输入先由原领域保存后才可纳入；已由冲突机制保存的整理材料属于可恢复数据。
- [已确认] 原统一位置地址只作来源说明，不作为恢复后自动生效的写入目标；访问凭据及设备接入授权须在目标按接入规则重新验证，不因持有数据文件自动获得原服务器访问能力。

## 交互流程和细节

用户进入导出 → 选择来源 → 查看范围及未同步说明 → 可先使用已有同步入口补齐当前设备已知进度，或按所选范围继续 → 进入快照生成。同步不能保证取得其他离线设备未知改动，不能据此宣称全端无遗漏。

## 数据范围

所选来源持有的全部工作空间领域数据与恢复必要信息，不是按当前界面筛选的列表，也不提供本轮未要求的任意字段裁剪。

## 前置能力

使用 [已有工作空间接入](../../存放环境管理/已有工作空间接入/已有工作空间接入.md)或已初始化绑定确认原空间；保存与同步状态复用已有共享机制。

## 边界情况与异常处理

[已确认] 统一位置不可访问时明确失败，允许用户主动改选本机来源，不静默降级。来源有登记数据但无法读取时提示本次无法完整导出该来源，不伪造为空领域。

## 验收标准

两个来源范围可区分；离线本机导出可选；未同步与冲突材料按实际来源纳入；停用领域不漏数据；界面隐藏不影响范围；没有把另一离线设备未知改动声称已包含。
