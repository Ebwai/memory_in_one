# 工作空间数据导出 [C]

状态：产品规则已确认；2026-10-26 已完成 N53：双来源确认、快照与文件交付整合。

## 功能描述

将工作空间的数据导出为用户可携带、可用于恢复的材料，而不仅导出当前界面中看得见的内容。

## 业务规则与约束

- 用户已明确：所有数据可导出，以支持迁移和恢复。
- [已确认] 覆盖所有已纳入信息领域的数据及恢复所需信息，不因领域停用或界面折叠而排除内容。
- [已确认] 导出应明确其数据来源、覆盖范围与未同步状态；不能宣称包含导出端尚未持有的其他设备离线改动。
- [已确认] 提供统一位置导出和本机可恢复数据导出，范围与来源明确。统一位置导出包含该位置已持有内容；本机导出包含本机已保存内容、未同步进度及冲突材料，离线也可执行，不自动改变来源。
- [已确认] 包含所选来源持有的全部领域数据、领域登记及恢复必要信息，不因停用、折叠或领域程序缺失而排除；普通未保存输入需先保存，不能冒充已包含。
- [已确认] 一致快照对应明确时点，之后发生的改动不混入本次材料；文件完整生成并校验后才反馈成功。具体包格式、校验算法和数据契约留给技术设计。

## 交互流程和细节

用户发起导出 → 选择来源并了解未同步覆盖范围 → 生成一致快照 → 选择保存位置并交付完整文件 → 取得完成或失败反馈。迁移用途遵循旧位置先停止写入的既有规则；本机可恢复材料不自动意味着已经取得迁移所需的全部统一进度。

## 数据范围

当前所选来源已持有的工作空间数据、领域登记与配置、内容身份与进度、必要同步及删除接续信息，以及该端持有的未同步操作与冲突材料。不是无限历史版本；领域程序缺失不妨碍原始数据保留。具体范围见导出范围确认。

## 前置能力

使用 [存放环境管理](../存放环境管理/存放环境管理.md)中的初始化或已有空间接入确定数据归属，复用既有可靠保存和领域含义。不要求迁移切换或上层存放环境管理整体验收已经完成，也不依赖恢复已经执行。

## 边界情况与异常处理

[已确认] 统一位置不可达时不静默改为本机导出；本机来源离线可导出；数据不可读不静默跳过；中断或失败不改变原空间、不以半成品报成功。已有有效导出文件在替换失败时保持可用。

## 验收路径

[已确认] 有未同步改动和冲突的本机可导出对应恢复材料；停用或暂时无领域程序的数据仍保留；导出期间继续编辑不产生前后混杂包；只有完整可校验文件才报成功；来源与覆盖边界明确。
