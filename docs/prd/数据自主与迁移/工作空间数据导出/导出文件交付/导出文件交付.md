# 导出文件交付 [C]

状态：产品规则已确认；2026-10-26 已完成 N52：保存位置与替换确认、完整写入及重读校验后的文件交付。

## 功能描述

将完整导出材料交付为用户可携带的本地文件，并明确反馈路径、范围和是否完成。

## 定位

```text
工作空间数据导出
└── 导出文件交付 [C] ●
```

## 业务规则与约束

- [已确认] 用户可选择保存位置；保存目标已有文件时明确选择是否替换，不静默覆盖。
- [已确认] 文件完整生成、落地并通过完整性检查后才显示成功；反馈保存位置、空间名称、来源及导出时点，保留覆盖范围说明供后续恢复核对。
- [已确认] 尚未完成的文件不能被显示为可用于恢复的成功结果；写入、校验或替换失败时保留原空间与原有有效文件。
- [已确认] 用户取消不删除或改变空间数据；再次导出是取得新快照，不自动改写此前用户保存的文件。
- 本节点不决定包扩展名、压缩格式、内部文件布局或校验算法。

## 交互流程和细节

用户确定保存位置 → 写入一致快照材料 → 检查完整性 → 成功后提供可找到的文件位置和范围摘要；失败提示保存未完成并允许重试。若需要重新生成快照，应明确新的导出时点。

## 数据范围

同级一致快照生成的材料及导出结果，不改变原空间中的数据或同步状态。

## 前置能力

引用同级 [一致快照生成](../一致快照生成/一致快照生成.md)。导出文件完整性检查只判断材料可交付，不代表所有未来软件和领域版本都兼容，具体恢复兼容性由恢复能力校验。

## 边界情况与异常处理

[已确认] 目标不可写、空间不足、写入被中断或完整性检查失败时不报成功；旧有效文件保持可用。无论是否联网，本机来源导出均使用相同交付规则。

## 验收标准

用户可找到成功文件且完整性校验通过；已有文件替换可取消；中断和失败不留下冒充成功的材料，也不破坏原数据或旧文件；范围与来源说明随文件保留。
