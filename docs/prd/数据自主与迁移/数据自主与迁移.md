# 数据自主与迁移 [C]

状态：产品规则已确认；2026-10-26 已完成 N60：双来源导出、隔离恢复及明确迁移整合。

## 功能描述

让用户掌握信息的存放环境，并能够携带数据迁移和恢复使用。

## 业务规则与约束

来自用户的已知要求：统一存放位置可以是自己的电脑，也可以是购买的服务器；所有数据可以导出，迁移后可恢复使用。

[已确认] 工作空间在同一时点使用一个已选定的统一位置，设备副本不是独立权威来源。导出需覆盖所有已纳入领域数据及恢复所需信息，不仅是当前界面可见内容；其他设备尚未同步且导出端未知的改动不能被声称已经包含。

[已确认] 默认在空白目标恢复，已有数据先停止并提示，不自动覆盖或合并；缺失领域扩展时保留相应数据，不静默丢弃。完整范围、未同步材料和恢复行为见对应已确认子节点。

## 交互流程和细节

用户选择存放环境并连接工作空间 → 导出可携带数据 → 准备目标环境 → 校验并恢复 → 继续使用。迁移复用上述能力，不另定义独立的数据集合。各步骤入口与失败反馈待下一层细化。

## 数据范围

所有已纳入信息领域的数据及其恢复所需信息。未同步进度、冲突材料、领域配置和兼容性信息的具体覆盖在导出与恢复子树定义；不承诺尚未存在的无限历史版本。

## 前置能力

数据导出复用既有领域与可靠保存含义，并使用初始化或接入所确定的工作空间；数据恢复使用已导出材料和已准备的空白目标。迁移切换复用导出与恢复，初始化和接入不以迁移完成为前提。服务器迁移是组合路径，不复制领域业务或同步机制。

## 边界情况与异常处理

[已确认] 导出端没有其他离线设备未同步内容时明确覆盖边界；恢复目标有数据时停止，不静默覆盖；缺失领域扩展不静默丢数据。包不完整、格式不兼容、恢复中断与切换统一位置的具体行为遵循相应已确认子节点。

## 后续已知输入

- 自己的电脑和云服务器均属于可选存放环境。
- 数据导出后可注入软件恢复，服务器可迁移。
- 未指定服务器供应商、部署方式或数据格式，本层不作技术选择。
