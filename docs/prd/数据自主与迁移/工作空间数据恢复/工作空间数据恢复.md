# 工作空间数据恢复 [C]

状态：产品规则已确认；2026-10-26 已完成 N57：恢复预览、确认、写入及按来源接续整合。

## 功能描述

将已导出材料注入目标环境，恢复原有信息及可继续处理的进度，支持迁移到另一台电脑或服务器。

## 业务规则与约束

- 用户已明确：携带数据即可恢复使用，服务器可以迁移。
- [已确认] 默认恢复到空白目标；目标已有数据时停止并提示，不自动覆盖或合并。
- [已确认] 恢复保留原空间及内容身份，并接续材料中的状态、未同步操作、删除进度和冲突成果，不能仅恢复文字，也不将已确认旧内容冒充新增批量上传。
- [已确认] 缺失某领域扩展时不丢弃其数据。[已确认] 该领域原始数据与接续材料以待启用状态保留，不提供不可验证的编辑或自动降级；以后补齐兼容程序再按原领域规则启用，期间仍可再次导出。
- [已确认] 核心包损坏或不兼容、目标非空时停止；写入失败或中断不启用半成品，不破坏原包和其他已有数据。
- [已确认] 统一位置材料恢复后需明确迁移切换才可成为正式统一位置；本机材料先恢复为原空间的本机可接续进度，不自动成为统一位置。需要替代原统一位置时明确确认覆盖范围并遵循迁移规则。

## 交互流程和细节

用户选择材料与空白目标 → 校验来源、身份、范围和兼容性 → 明确恢复 → 写入并校验可恢复结果 → 展示成功与待处理项 → 按材料来源接入原空间或进入迁移切换。切换规则不由导入动作隐式决定。

## 数据范围

同级导出能力提供的可恢复材料及目标工作空间，不默认合并目标已有的另一份数据。

## 前置能力

引用同级 [工作空间数据导出](../工作空间数据导出/工作空间数据导出.md)及已准备的空白目标环境，按材料中的领域含义恢复。正式迁移位置切换是在恢复成功后的步骤，不反向作为恢复前置，避免循环依赖。

## 边界情况与异常处理

[已确认] 缺失领域程序只限制该领域启用，不丢其数据；恢复失败不显示可正常使用的半成品；重试先核对原恢复结果，避免产生重复空间。材料之外的更新不声称已经恢复，旧包重新接入时沿既有同步与冲突机制，不让旧内容自动覆盖新进度。

## 验收路径

[已确认] 含停用领域、未同步操作和冲突的导出材料可保持原身份与状态恢复；缺失程序的数据可保留再导出；非空目标停止；中断不误报成功；本机来源不自动变成统一位置；重新接入不重复操作或复活旧内容。
