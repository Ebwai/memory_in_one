# 恢复材料与目标校验 [C]

状态：产品规则已确认；2026-10-26 已完成 N54：材料完整性、核心兼容性、原关系和空白目标校验，预览不写入。

## 功能描述

在写入前确认恢复材料的范围、身份、完整性与兼容性，并确认目标为空白，供用户判断是否继续恢复。

## 定位

```text
工作空间数据恢复
└── 恢复材料与目标校验 [C] ●
```

## 业务规则与约束

- [已确认] 用户选择导出文件和目标后，展示空间身份与名称、来源、导出时点、覆盖领域及未同步或冲突摘要，不仅依据文件名判断内容。
- [已确认] 核对包完整性、核心兼容性、必要关系及目标是否空白；包损坏、核心格式不支持或目标已有数据时停止，不尝试部分覆盖。
- [已确认] 区分统一位置来源与本机来源，说明该材料实际覆盖边界；本机材料不声称含其他设备未上传成果。
- [已确认] 缺失或不兼容领域程序与核心包损坏区分：数据及接续材料能完整保留时，可继续恢复为待启用领域，明确指出不能正常编辑的领域；无法保证保留时停止，不跳过该领域。
- [已确认] 此步骤只校验和展示，不写入目标空间、不改变原绑定；用户确认恢复才进入写入。

## 交互流程和细节

用户选择材料与目标 → 校验并展示恢复摘要及不可用领域 → 用户可取消或明确恢复 → 通过后进入恢复写入。失败保留文件与目标选择，给出可处理原因。

## 数据范围

导出材料中的身份、来源、范围和兼容信息，以及目标环境当前状态。使用已有导出含义，不另定义一套恢复包格式。

## 前置能力

引用 [工作空间数据导出](../../工作空间数据导出/工作空间数据导出.md)的材料与覆盖规则，以及可检查的目标环境；不要求迁移切换已完成。

## 边界情况与异常处理

[已确认] 校验期间目标已被其他操作写入时，正式写入前再次核对并停止；验证通过不等于最终写入必定成功。核心材料缺失不因某领域当前停用就忽略。

## 验收标准

来源与范围可识别；损坏、不兼容核心和非空目标被阻止；缺失程序明确列出并保留数据；取消不改变绑定或目标；正式写入前目标被占用不会被覆盖。
