# 存放环境管理 [C]

## 功能描述

让用户选择并管理工作空间的统一存放环境，让设备接入正确的同一份信息。负责存放位置与接入，不重复定义同步传输。

## 业务规则与约束

- 用户已明确：统一位置可以是自己的电脑，也可以是购买的服务器，不指定供应商。
- [已确认] 一个工作空间同一时点只有一个已选定的统一位置；本机副本与待同步进度仍归属于原工作空间。
- [已确认] 用户能够辨认当前接入的是哪份工作空间及其位置，连接失败不自动另建空空间替代。
- [已确认] 首次默认可在本机创建，不要求外网；也可选择已准备好的自主管理服务器。新增与接入明确区分，不覆盖已有空间，不在连接失败时自动新建替代。
- [已确认] 接入核对空间身份及访问条件，失败保留已有本机成果。迁移先停用旧位置的写入，目标恢复并校验后明确切换，避免同时存在两个可写统一位置。
- 本轮不指定部署工具、网络协议或数据格式，也不替用户购买或部署第三方云资源。

## 交互流程和细节

首次用户创建或连接已有工作空间 → 核对正确位置后进入领域。迁移时，旧位置停止写入 → 复用导出及恢复准备目标 → 明确切换 → 原设备改接原空间的新位置，继续本机待同步进度。具体路径见子节点，均已确认。

## 数据范围

工作空间的归属、统一位置和设备接入关系；不同信息领域内容不在本节点重新定义。

## 前置能力

初始化和已有空间接入可独立成立；迁移切换复用数据导出及恢复。不能反向要求上层存放环境管理全部完成才可进行导出或恢复。同步使用本能力确定的原工作空间与生效位置，不重复定义数据传输。

## 边界情况与异常处理

[已确认] 初始化失败不显示虚假的空空间成功；接入错误空间不发送原空间改动；旧服务器不可达时，正式切换需用户明确确认已停用或隔离旧位置，不能自动同时启用第二处写入。失败保留本机已有内容、绑定与未同步进度。
