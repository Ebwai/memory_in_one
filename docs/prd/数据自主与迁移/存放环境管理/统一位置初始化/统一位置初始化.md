# 统一位置初始化 [C]

状态：原子节点及以下具体规则已于 2026-10-25 经用户确认。

实现状态：N05 已于 2026-10-25 完成，支持本机或已准备自管服务创建，原请求核对、不覆盖已有目标、失败保留输入，以及确认后的本机绑定和重启恢复。权威文件与本机副本分离，本机地址仅回环访问。两个运行时各通过 66 项，窗口测试共 4 项通过。远端使用独立回环服务验证，未声称已部署云环境。具体语义见 [TDD 导航](../../../../TDD.md)。

## 功能描述

在用户选定的环境建立一份新的工作空间，并明确它的唯一统一位置。

## 定位

```text
存放环境管理
└── 统一位置初始化 [C] ●
```

## 业务规则与约束

- [已确认] 首次入口明确区分“创建新工作空间”和“连接已有工作空间”；创建默认提供本机选项，可在没有外网时完成。
- [已确认] 创建新空间可选自己的电脑或已准备好的自主管理服务器；远端环境需可达且具备有效接入条件。本节点不包含云资源购买或代为部署。
- [已确认] 工作空间名称可预填“我的工作空间”，用户可修改；忽略首尾空白后不能为空。不以名称相同推定是同一空间。
- [已确认] 目标已存在工作空间时不覆盖，提示改用已有空间接入；若用户要恢复备份，则进入既有恢复路径，不将初始化新空空间冒充恢复。
- [已确认] 成功后明确显示当前空间和统一位置；本机创建成功不声称其他设备已能通过网络访问，外部设备仍需正确接入。

## 交互流程和细节

用户选择创建 → 选择存放环境并填写必要信息 → 校验目标可用且没有会被覆盖的空间 → 建立空间 → 显示成功后进入工作空间。取消或失败不建立一个供后续误用的替代绑定。

## 数据范围

新工作空间的身份、名称、统一位置及本机绑定。领域启用与注册由信息领域管理定义，不在这里复制待办设置。

## 前置能力

具有可用的选定目标环境；不要求既有导出、恢复或迁移已完成。访问凭据的具体形式与技术部署方案留给后续设计。

## 边界情况与异常处理

[已确认] 名称无效、环境不可达或无法创建时，保留填写内容并说明原因。创建结果不明时核对原创建结果，不因重试产生多个空间；成功前不清除用户此前保存的空间或数据。

## 验收标准

本机首次创建无需外网；远端目标不可用时不伪报成功；目标已有空间不覆盖；创建与连接入口明确区分；重试不意外新建多份空间。
