# 统一位置迁移切换 [C]

状态：产品规则已确认；2026-10-26 已完成 N58：旧位置停写、目标待启用、明确切换及不可达旧位置隔离确认。

## 功能描述

在原空间数据已恢复至另一环境后，明确变更唯一生效的统一位置，让原设备继续处理同一份进度。

## 定位

```text
存放环境管理
└── 统一位置迁移切换 [C] ●
```

## 业务规则与约束

- [已确认] 正式迁移切换前，旧统一位置先停止接受新写入，再取得用于迁移的导出材料；设备仍可按已有离线规则在本机留下待同步操作。
- [已确认] 目标恢复并校验成功、保持原工作空间身份后，用户明确切换至新位置；准备或恢复目标不自动将它变为第二个可写统一位置。
- [已确认] 旧位置可达时让其停止写入；不可达时需用户明确确认旧位置已经停用或隔离后才能完成正式切换，不自动猜测旧位置已经失效。
- [已确认] 切换成功后旧位置维持不接受新写入；原设备改接同一空间的新位置，沿原操作补同步，遇到较新进度使用既有冲突机制，不自动覆盖或复活内容。
- [已确认] 切换失败保留原绑定、已保存内容、待同步材料及已准备的目标，明确当前哪一位置可写；不自动让两处同时恢复写入。
- [已确认] 原空间仍有其他离线设备时，不能宣称其未知改动已经包含在迁移包中；设备之后可携其本机进度接入新位置，不擅自另建空间。

## 交互流程和细节

用户发起迁移 → 旧统一位置停止接收新写入 → 导出材料 → 准备并恢复目标 → 校验原空间身份和数据 → 明确切换 → 各设备按相同空间身份改接新位置并接续进度。旧位置不可达时需明确确认已停用或隔离；材料准备及恢复分别复用既有节点。

## 数据范围

原空间身份、新旧统一位置、迁移材料和原设备的本机待同步进度；本节点不重定义导出包内容或恢复数据格式。

## 边界情况与异常处理

[已确认] 旧位置无法确认停用、目标恢复失败、目标身份不符或目标已被当作另一份空间使用时，不完成正式切换；明确保留的材料与当前状态。迁移中断后重新进入时核对已完成步骤，不重复建立空间，也不隐式恢复旧位置写入。

## 验收标准

同一空间可迁移至新环境并被原设备接续；正常路径中不会同时存在两个可写统一位置；目标未恢复成功不切换；旧位置不可达需要明确停用确认；未同步进度不丢、不同身份不混入；中断后可核对并接续。
