# 已有工作空间接入 [C]

状态：原子节点及以下具体规则已于 2026-10-25 经用户确认。

实现状态：2026-10-25 已实现 N06 的身份核验、信息确认和本机绑定，支持本机已有目录与自管服务。身份不符或接入失败保留原绑定及副本，离线重启不创建替代空间。内容获取、离线业务操作、同步反馈与迁移切换随对应后续节点整合验收，不将绑定成功视为内容已同步。见 [TDD 导航](../../../../TDD.md)。

## 功能描述

让当前设备连接已有空间，核对身份与访问条件后接续同一份内容，而不是为该设备另建一份空间。

## 定位

```text
存放环境管理
└── 已有工作空间接入 [C] ●
```

## 业务规则与约束

- [已确认] 用户选择接入已有空间，提供位置及该环境要求的访问凭据；取得并显示目标空间身份与名称后进入，不仅凭名称匹配。
- [已确认] 本机已有同一空间绑定时，重新打开优先接续该绑定；暂时不可达使用已确认的离线机制，不要求重新创建空间。
- [已确认] 输入目标与已有本机空间身份不一致时停止接入并明确提示，不将原空间待同步内容自动传入新空间。
- [已确认] 接入失败保留当前已确认绑定、本机内容及未同步进度；连接失败不能被解释为远端为空，也不能自动另建替代空间。
- [已确认] 接入正确空间后复用既有进度获取及同步反馈；迁移后的新地址还需遵循统一位置迁移切换的身份与生效位置规则。

## 交互流程和细节

用户输入已有空间位置和必要凭据 → 校验可达性、访问条件及空间身份 → 展示并核对空间信息 → 接入后获取进度。失败保留输入并提示可处理原因。已有本机绑定离线时可接续本机副本。

## 数据范围

目标空间身份、位置、访问条件及当前设备的绑定和本机已有进度。本轮不新增多空间列表或任意跨空间合并能力。

## 前置能力

已有可接入工作空间；接入成功后的内容获取复用已确认同步机制。本节点先确定正确接入对象，不以已完成全部同步作为取得绑定的前提。

## 边界情况与异常处理

[已确认] 凭据不满足条件、地址错误、空间不存在或目标身份不符时分别给予可理解反馈，不显示技术堆栈。原设备离线已绑定时不因本次连接失败抹去可用本机内容。

## 验收标准

新设备可连接同一空间并接续内容；同名但不同身份的空间不会混入原数据；接入失败保留原绑定；已有绑定的离线启动不要求重新创建；改接迁移地址不会意外新建空间。
