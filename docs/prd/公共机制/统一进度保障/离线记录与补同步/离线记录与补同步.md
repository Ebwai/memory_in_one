# 离线记录与补同步 [M]

状态：节点、三个直接子节点及具体规则已于 2026-10-25 经用户确认，非原子节点。

## 功能描述

在统一位置暂时不可访问时保留记录能力，并在重新连接后继续同步，避免碎片记录依赖当时的网络状况。

## 业务规则与约束

- [已确认] 暂时离线时可以在本机留下内容，并明确标记尚未同步；可靠本机保存后应用重启仍可找回。
- [已确认] 连接恢复后补同步到原工作空间，不因断网或应用重新打开而复制为另一个独立权威来源。
- [已确认] 没有本机保存成功时不能以“等待同步”掩盖保存失败。
- [已确认] 补同步遇到并发改动时使用共享冲突机制，不静默覆盖统一位置的新进度。
- [已确认] 对已在本机初始化的工作空间，离线允许查看本机已保存内容，并继续执行领域本来支持的新增、修改、状态变更和删除，不要求先恢复网络。
- [已确认] 同一内容处于结果待确认或未解决冲突时，不继续叠加写操作；其他独立内容不受影响。本机已保存、单纯等待同步不视为结果不明，可按领域规则继续操作。
- [已确认] 首次创建及选择本机作为统一位置由数据自主与迁移的初始化规则定义，本机创建无需外网。本节点接续原工作空间，不以“没连过服务器”为由擅自创建另一份工作空间。

## 交互流程和细节

用户暂时无法连接统一位置 → 查看本机内容并按领域规则继续操作 → 本机可靠保存、显示待同步 → 应用重新进入时接续本机内容 → 恢复连接后沿原操作补同步，必要时转入冲突处理。详细路径见三个子节点，均已确认。

## 数据范围

已取得的本机内容和尚未同步的本机操作；只作为原工作空间的待同步进度，不能冒充已完成全局同步。

## 前置能力

复用同级 [可靠保存与结果确认](../可靠保存与结果确认/可靠保存与结果确认.md)、[跨设备进度同步](../跨设备进度同步/跨设备进度同步.md)，并在需要时引用 [并发修改与冲突处理](../并发修改与冲突处理/并发修改与冲突处理.md)。

## 边界情况与异常处理

[已确认] 断网不清空内容，不改变当前工作空间；本机无法保存时保留输入，不以待同步掩盖失败；首次没有本机副本时明确提示暂无可用本机内容，不冒充远端为空；恢复后同步冲突不静默覆盖成果。服务器长期不可用时仍保留已有内容与待同步进度，不承诺该期间其他设备已能取得。

## 验收路径

[已确认] 在已有本机工作空间中断网，仍可查看、执行领域允许的操作并保存；重启后可接续；恢复连接后改动进入原工作空间；遇到冲突保留待处理状态，无冲突独立内容继续同步。
