# 连接恢复接续 [M]

状态：原子节点及以下具体规则已于 2026-10-25 经用户确认。

## 功能描述

在连接恢复或重新进入应用时，接续原工作空间的未完成操作，并取得统一位置的新进度。

## 定位

```text
离线记录与补同步
└── 连接恢复接续 [M] ●
```

## 业务规则与约束

- [已确认] 应用运行时连接恢复，或重新打开已有工作空间且可连接时，自动接续未完成同步；仍离线则保持已有本机成果与待同步状态。
- [已确认] 使用原工作空间和原操作，不把离线内容复制到一个新的默认工作空间，不把重启当作再次提交全部动作。
- [已确认] 复用现有上传、获取及结果核对；核对到原操作成功时接续结果，不能重复创建或反复执行。
- [已确认] 同步遇到并发改动、远端删除或本机未提交输入时，按同步与冲突机制保留可处理成果；不因“恢复连接”强行覆盖一方。
- [已确认] 个别冲突不阻塞其他独立内容继续同步；恢复过程中再次断网仍保留已完成结果和未完成进度，不从头误执行一遍。

## 交互流程和细节

本机已有待同步操作 → 恢复连接或重启后重新连接 → 自动核对并继续原操作 → 取得最新已确认进度 → 按结果刷新状态或进入冲突处理。正常结果无需逐项确认，用户也可使用已定义的立即同步入口。

## 数据范围

当前原工作空间中未完成的操作、已确认结果及统一位置的新进度，不涉及迁移至其他服务器或切换工作空间。

## 前置能力

复用 [跨设备进度同步](../../跨设备进度同步/跨设备进度同步.md)、[重复提交与结果恢复](../../可靠保存与结果确认/重复提交与结果恢复/重复提交与结果恢复.md)，遇到冲突引用 [并发修改与冲突处理](../../并发修改与冲突处理/并发修改与冲突处理.md)。

## 边界情况与异常处理

[已确认] 统一位置不匹配时停止把原进度发送到错误目标并提示；不能因目标不可用而自动合并到其他空间。恢复后的正常联网时效沿用已确认的同步目标，不对需要人工处理的冲突承诺自动完成时限。

## 验收标准

离线保存后直接恢复连接、退出后再联网重启、补同步中再次断网，均能接续而不重复操作；内容回到原空间；独立内容可继续同步；冲突明确保留，旧副本不自动覆盖或复活已删除内容。
