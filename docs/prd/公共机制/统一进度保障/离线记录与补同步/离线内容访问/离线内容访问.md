# 离线内容访问 [C]

状态：原子节点及以下具体规则已于 2026-10-25 经用户确认。

## 功能描述

统一位置不可达时，查看原工作空间在本机已经可靠保存的内容与当前本机进度。

## 定位

```text
离线记录与补同步
└── 离线内容访问 [C] ●
```

## 业务规则与约束

- [已确认] 已初始化工作空间在启动时离线，仍可进入已有领域并查看本机已保存内容，不将此次连接成功作为查看已有副本的条件；工作空间的接入与访问规则由后续接入需求确定。
- [已确认] 明确提示当前离线或无法确认最新进度；本机内容包含已确认保存在本机的未同步成果，不声称与统一位置实时一致。
- [已确认] 本机已有内容按各领域现行规则呈现，不因为断网额外建立副本或清空列表。
- [已确认] 没有可用本机副本时提示“暂无可用的本机内容”，不能将其表述为统一位置没有任何内容。首次初始化入口由数据自主与迁移确定。

## 交互流程和细节

前置条件：本机已有该工作空间的初始化信息；读取既有副本无需依赖本次网络请求成功。

用户打开应用 → 识别统一位置暂不可达 → 显示本机内容及状态 → 可查看详情并按领域规则继续使用。应用重新打开仍接续已保存内容。

## 数据范围

原工作空间在本机已经保存的内容、未同步进度及领域状态，不含尚未在本机取得的远端新增内容。

## 前置能力

复用 [本机内容持久保存](../../可靠保存与结果确认/本机内容持久保存/本机内容持久保存.md)和 [保存与同步状态呈现](../../可靠保存与结果确认/保存与同步状态呈现/保存与同步状态呈现.md)；具体内容呈现由所属领域负责。

## 边界情况与异常处理

[已确认] 本机读取失败时明确说明不能读取，不将损坏或加载失败冒充空内容；仍可读取的已保存成果不因网络异常被抹除。恢复网络后的更新由连接恢复接续处理。

## 验收标准

已有本机副本在离线启动和重启后均可查看；离线状态明确；本机无副本与远端真实空内容可区分；领域查看规则保持一致。
