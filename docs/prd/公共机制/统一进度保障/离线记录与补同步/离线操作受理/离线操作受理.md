# 离线操作受理 [M]

状态：原子节点及以下具体规则已于 2026-10-25 经用户确认。

## 功能描述

在统一位置不可达时接受原工作空间中所属领域允许的操作，并通过既有本机保存能力可靠留下待同步进度。

## 定位

```text
离线记录与补同步
└── 离线操作受理 [M] ●
```

## 业务规则与约束

- [已确认] 本机已有该工作空间时，离线可新增内容，并对本机可用内容执行领域已支持的修改、状态变更和删除；不新增领域本来不支持的操作。
- [已确认] 各操作复用在线时的内容校验、确认、取消等领域规则，不要求先联网再完成本机保存。
- [已确认] 本机成功后依领域规则更新当前界面，标明待同步；本机失败保留输入或此前状态，不把失败说成已保存待同步。
- [已确认] 本机保存明确成功、仅等待同步时，可继续接受该领域允许的后续操作；同一内容处于结果待确认或待解决冲突时，暂停进一步写入，其他独立内容继续使用。
- [已确认] 未同步操作与所属内容在重启后可接续；本机删除也保留传播所需进度，不因重启自动恢复已删除内容。领域是否有撤销或回收站仍由领域定义。

## 交互流程和细节

前置条件：工作空间已在本机初始化，所需内容可用，该领域允许对应操作，且当前内容无待处理的不明结果或冲突。

用户在离线状态执行领域操作 → 按既有规则校验与确认 → 本机保存 → 明确反馈待同步或保存失败。恢复连接后交给连接恢复接续。

## 数据范围

原工作空间各领域允许的本机操作及待同步进度。todo-list 的具体离线操作清单只在 todo-list 节点定义，本机制不规定待办完成或日期含义。

## 前置能力

复用 [可靠保存与结果确认](../../可靠保存与结果确认/可靠保存与结果确认.md)，沿用对应领域既有操作；不以网络同步完成作为本机成功的前提。

## 边界情况与异常处理

[已确认] 操作期间断网不清空输入；已保存在本机的动作仍为同一动作，不因网络变化重复创建。当前内容没有可用本机副本时不擅自覆盖远端；初始化缺失时使用已有工作空间设置入口，不自动创建另一个工作空间冒充原空间。

## 验收标准

断网后可按领域规则新增及处理可用本机内容；成功后重启可接续，失败不丢输入；同一内容待核对或冲突时暂停写入，其他内容仍可使用；联网与离线不产生两套领域规则。
