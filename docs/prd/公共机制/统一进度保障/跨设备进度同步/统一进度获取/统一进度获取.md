# 统一进度获取 [M]

状态：原子节点及以下具体规则已于 2026-10-25 经用户确认。

## 功能描述

取得统一位置已确认的内容进度，让当前设备继续处理同一份信息。

## 定位

```text
跨设备进度同步
└── 统一进度获取 [M] ●
```

## 业务规则与约束

- [已确认] 获取的是当前已选定工作空间的新增、更新及删除结果；不将下载内容变为新的独立记录。
- [已确认] 本机无未同步改动时接续统一位置确认的进度；存在未同步改动或正在编辑的输入时，不静默覆盖。可否合并以及处理路径引用共享冲突机制。
- [已确认] 获取到的进度先可靠保存在本机再作为已取得结果呈现，应用重启后仍可接续。
- [已确认] 较旧的返回结果不让本机已确认的新进度倒退；单次失败或未取得完整结果不被理解为统一位置已经清空。

## 交互流程和细节

同步触发 → 获取统一位置的已确认进度 → 保留尚未提交的输入和未同步成果 → 接续可接受的更新并保存 → 领域界面按当前内容刷新。不能安全接续的改动交由冲突机制。

## 数据范围

统一位置当前工作空间的信息、更新及删除结果；尚未提交的输入仍属于当前编辑过程，不因同步自动提交或放弃。

## 前置能力

复用 [可靠保存与结果确认](../../可靠保存与结果确认/可靠保存与结果确认.md)，引用 [并发修改与冲突处理](../../并发修改与冲突处理/并发修改与冲突处理.md)。各领域负责按自身规则显示取得的内容。

## 边界情况与异常处理

[已确认] 连接失败保留已保存内容并说明无法取得最新进度；本机无法保存取得结果时不标记为已完成获取；部分获取失败不会删除未取得部分的原内容。权限或工作空间不匹配时停止接续并提示，不混入另一份工作空间。

## 验收标准

另一设备确认的新增和修改可在本机接续；获取失败不清空原有内容；重启可找回已取得内容；未提交输入和未同步改动不被静默覆盖；旧结果不导致倒退。
