# 冲突成果保留 [M]

状态：原子节点及以下具体规则已于 2026-10-25 经用户确认。

## 功能描述

可靠留下不能自动合并的成果与必要比较背景，确保用户以后能够处理，而不是在同步时丢掉其中一方。

## 定位

```text
并发修改与冲突处理
└── 冲突成果保留 [M] ●
```

## 业务规则与约束

- [已确认] 可靠保留本机未合并成果、已取得的统一位置相关进度，以及用户尚未提交的冲突整理内容；应用重新打开后仍可继续处理。
- [已确认] 保留内容与原工作空间、原内容关联，不自动作为另一条普通内容出现在领域列表中，不伪装为已同步。
- [已确认] 当前内容标记待处理，暂停普通写操作；用户可在冲突解决路径中整理与选择，其他独立内容照常使用。
- [已确认] 在用户明确选择并确认提交前，不丢弃任何一方尚未合并成果；解决过程本机保存或同步失败时，保留待处理材料与选择。
- [已确认] 统一位置后续再次变化时保留现有材料并补充新进度，不能悄悄替换用户正在整理的文字。

## 交互流程和细节

差异无法安全合并 → 先可靠留下成果 → 标记可处理的冲突 → 用户可立即处理或稍后返回。关闭应用再打开时仍能找到原冲突与已有整理内容。

## 数据范围

原内容的冲突材料与用户待确认选择，不是无限历史版本，也不新增日常回收站。材料退出待处理状态的条件是选择结果已按保存和同步规则确认，具体存储清理设计留给后续技术设计。

## 前置能力

引用同级差异判定结果，以及 [本机内容持久保存](../../可靠保存与结果确认/本机内容持久保存/本机内容持久保存.md)。向冲突解决选择提供已保留材料，不反向要求传输实现。

## 边界情况与异常处理

[已确认] 无法保留冲突材料时明确提示并停止覆盖原有成果，不能声称已安全接续。已有材料不因某次获取失败消失；部分材料暂时无法取得时明确说明，不伪造另一方为空。

## 验收标准

冲突后退出、重启、暂时离线仍能继续查看本机已保留材料；另一方内容不被静默丢弃；冲突不自动创建第二条普通记录；保存失败或远端再变化不抹掉用户整理内容。
