# 并发差异判定与自动合并 [M]

状态：原子节点及以下具体规则已于 2026-10-25 经用户确认。

## 功能描述

比较同一份内容在多个入口的改动，安全接续不冲突的成果，其余交给冲突处理，不通过最后到达自动淘汰一方。

## 定位

```text
并发修改与冲突处理
└── 并发差异判定与自动合并 [M] ●
```

## 业务规则与约束

- [已确认] 只有能够比较同一内容的共同已确认进度，且领域声明相关属性可独立处理时，才自动合并；缺少依据时进入待处理冲突。
- [已确认] 仅一方修改某属性时保留该修改；双方修改不同独立属性时保留双方结果；双方把同一属性改成同一值时接续该值；同属性不同值需要用户处理。
- [已确认] 不自动拼接或改写文字，不按设备时间或到达先后强行选一方。合并结果仍须满足领域有效性要求，否则进入冲突处理。
- [已确认] 同一内容双方均删除可接续删除；删除与编辑同时发生时不自动合并，也不自动恢复。
- [已确认] 不同内容的改动各自处理；不同设备主动新建相同文字仍是不同内容，不按文字自动去重。

## 交互流程和细节

获得相关改动及比较依据 → 依据领域规则判断 → 能安全合并则给出原内容的合并结果 → 不能安全合并则交给成果保留及解决选择。自动合并无需用户逐条确认。

## 数据范围

同一内容的共同已确认进度、相关改动及领域声明的属性含义。不在本节点定义待办文字、日期和完成的特殊规则。

## 前置能力

需要具体领域的冲突判定声明与可比较的进度；缺少声明则保守进入冲突，不反向依赖网络传输。后续保存与同步处理本节点给出的结果。

## 边界情况与异常处理

[已确认] 领域规则不可用或比较依据缺失时不猜测、不丢成果。重复收到已经处理过的改动不再造成额外分裂；旧改动不能覆盖新确认进度。

## 验收标准

不同独立属性合并后保留双方结果；同属性同值可接续，不同值产生待处理冲突；无依据、无领域声明及删除与编辑冲突时均不自动覆盖；最终不创建多份独立事实。
