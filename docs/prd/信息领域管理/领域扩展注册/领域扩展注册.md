# 领域扩展注册 [C]

状态：原子节点及以下具体规则已于 2026-10-25 经用户确认。

实现状态（2026-10-25）：N07 已实现注册预览、身份与兼容校验、重复注册保护和缺程序补齐。登记与本机程序分离；联网同步及导出由后续节点接入。

## 功能描述

将内置或用户提供的自定义信息领域登记进工作空间，明确它的身份、兼容性和可用程序，而不重复建立同一领域的数据。

## 定位

```text
信息领域管理
└── 领域扩展注册 [C] ●
```

## 业务规则与约束

- [已确认] 支持用户提供的自定义扩展，注册前展示名称、稳定身份、版本、兼容性及所需数据访问范围；程序载体和接口格式留给技术设计。
- [已确认] 稳定领域身份在同一工作空间唯一，不仅按名称判断；同名不同身份不能互相借用数据。
- [已确认] 已登记相同身份的重复注册不重建领域。恢复后仅缺失程序时，可明确补齐相同身份的兼容程序并接续旧数据，不清空登记与内容。
- [已确认] 不兼容、身份冲突或企图以另一程序覆盖已有数据时拒绝静默替换，并给出可理解原因；本轮不将程序升级或数据格式迁移隐式塞进重复注册。
- [已确认] 领域登记随工作空间保存、同步和导出；程序安装及可用性是设备本地状态，不因同步到登记而自动安装或执行自定义代码。
- [已确认] 注册成功后可由用户明确启用；内置领域的默认启用映射由各领域单独定义。系统提供的数据接口默认只开放该扩展所属领域，不默认授予跨领域访问。

## 交互流程和细节

用户从目录选择添加扩展 → 提供自定义扩展 → 查看身份及兼容信息 → 校验并明确注册 → 保存登记及本机程序信息 → 展示成功，可继续启用；已有登记仅缺程序时明确提示为补齐程序。

## 数据范围

领域身份、名称、版本、兼容声明、工作空间登记与当前设备程序可用信息。不因注册动作覆盖已有领域内容。

## 前置能力

需要已有工作空间绑定与可靠保存能力；登记后复用共享同步及导出，不要求领域已可进入才可注册。

## 边界情况与异常处理

[已确认] 失败保留原登记和数据，不创建半可用领域；结果不明核对原注册，不重复建领域。离线注册可在本机保存为待同步，联网发生同身份不兼容登记时交给明确处理，不静默替换已有程序或数据。

## 验收标准

可注册用户扩展；重复注册不重建；缺失程序可补齐并接续原数据；同名不同身份不混用；不兼容不覆盖；登记同步不等于其他设备自动安装代码。
