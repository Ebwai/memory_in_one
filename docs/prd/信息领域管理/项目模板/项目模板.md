# 项目模板 [C]

状态：2026-11-01 已实现并验证项目想法、简单待办、完成恢复、独立实例及生命周期。

## 功能描述

提供创建具体项目插件的预设模板。

## 定位

信息领域管理 → 项目模板 → 项目的想法、项目的待办事项。

## 业务规则与约束

- 项目模板目前包含项目的想法、项目的待办事项两个方面。
- 项目的想法采用逐条添加的列表形式，每条想法归属于当前项目插件。
- 项目想法支持逐条添加、修改、删除，并以列表回看。
- 项目待办本期仅支持添加、修改、完成、删除；不纳入子待办、截止日期、备注、周期重复。
- 项目想法采用纯文本，新添加的记录排在最前。
- 项目待办未完成项在前；完成后移到已完成区，允许恢复为未完成。
- 删除单条项目想法或待办前提示确认；取消则保留内容。
- 保存与同步复用现有公共能力。
- 同一模板创建的多个项目插件各自拥有独立内容。
- 项目插件可重命名、整体删除；整体删除须先确认将删除其中全部想法与待办，取消则保留原内容。
- 项目待办与既有 todo-list 独立，不互相展示或联动状态。

## 交互流程和细节

通过 [[../预设模板创建插件/预设模板创建插件.md|预设模板创建插件]] 创建具体项目插件后，从目录进入，切换“项目想法”或“项目待办”，录入纯文本并保存。列表可编辑、删除；项目待办可完成或恢复。输入仅在本机保存成功后清空，删除单条内容须确认；切换及退出复用草稿保护。

## 数据范围

各项目插件所属的想法与待办事项。

## 前置能力

预设模板创建插件。是否复用既有待办的部分产品行为需逐项确认，内容独立不代表默认继承全部功能。

## 边界情况与异常处理

两个方面的内容独立展示；空白内容不能保存。失败保留输入，停用或整体删除后的实例不能继续写入。整体删除采用逻辑删除，历史操作及恢复材料沿既有保障机制保留。
