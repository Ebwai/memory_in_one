# 领域启用状态管理 [C]

状态：原子节点及以下具体规则已于 2026-10-25 经用户确认。

实现状态（2026-10-25）：N08 已实现工作空间启停状态的本机可靠保存、缺程序门禁及草稿处理；停用不删既有内容或待同步材料。跨设备传播与冲突沿后续机制整合。

## 功能描述

管理领域在工作空间中的启用或停用状态，保留用户已有内容与进度。

## 定位

```text
信息领域管理
└── 领域启用状态管理 [C] ●
```

## 业务规则与约束

- [已确认] 启用状态属于工作空间，经既有同步规则传播；程序是否存在和兼容属于设备本地，不因一端缺程序而自动停用整个空间的该领域。
- [已确认] 可明确启用当前设备具备兼容程序的领域；停用停止该领域的新业务操作及自动业务行为，不删除登记、数据、未同步进度或冲突材料。
- [已确认] 停用不禁止维护已有保存成果：兼容处理可用时既有待同步进度继续接续，程序不可用或无法判断时保留待处理状态，不丢弃材料，不阻塞其他领域。
- [已确认] 停用前若有未保存输入，用户先保存或明确放弃；取消则保持原状，不能静默清空。其他离线设备获知停用前已保存的操作仍保留并按共享同步和冲突规则处理。
- [已确认] 再启用回到原内容集合，不以新领域替代；停用期间内容与待处理材料仍可导出恢复。

## 交互流程和细节

用户从管理目录选择启用或停用 → 查看工作空间作用范围及未保存输入 → 明确操作 → 可靠保存状态并反馈。失败保持此前已确认状态，结果不明先核对。具体业务入口的启停映射由领域自身定义。

## 数据范围

工作空间共享的领域启用状态，不移除程序或删除业务内容。

## 前置能力

引用同级 [领域扩展注册](../领域扩展注册/领域扩展注册.md)的登记与兼容信息，复用保存、同步和冲突能力；管理入口不依赖领域业务界面已启用。

## 边界情况与异常处理

[已确认] 两端并发启停复用共享冲突机制；程序缺失时无法在该设备启用，但仍可看到登记及数据保留状态。状态尚未同步不能伪报所有设备已经停止业务。

## 验收标准

启停范围明确并同步；停用不删数据；未保存输入不静默丢失；再启用接续原内容；离线旧设备已保存成果保留；其他领域不受影响。
