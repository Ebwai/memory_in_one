# 领域目录与进入 [C]

状态：原子节点及以下具体规则已于 2026-10-25 经用户确认。

实现状态（2026-10-25）：N10 已实现本机目录、状态区分、兼容门禁及声明式领域业务入口；读取失败不清空已显示成果。最新远端状态尚未确认，联网同步仍待后续实现。

## 功能描述

用统一界面展示工作空间中已登记的信息领域及其状态，并进入适合该领域的业务界面。

## 定位

```text
信息领域管理
└── 领域目录与进入 [C] ●
```

## 业务规则与约束

- [已确认] 目录展示领域名称、稳定身份、所登记版本、工作空间启用状态，以及当前设备的程序可用性；停用或缺失程序的领域也不从管理目录消失。
- [已确认] 启用且具有兼容程序的领域可进入其业务界面；其他状态说明原因并提供启用或补齐程序入口，不以空业务列表掩盖不可用。
- [已确认] 业务呈现由领域定义，管理目录不强制所有领域提供待办、完成勾选或悬浮窗。
- [已确认] 目录支持从同一工作空间进入各领域，不将入口切换解释为创建另一份内容。离线时按已有本机登记与状态呈现，明确最新状态尚未确认。
- [已确认] 目录提供扩展注册与启停管理入口；已登记但不可用的数据仍可通过工作空间导出保留。

## 交互流程和细节

用户打开工作空间管理界面 → 查看已登记领域及状态 → 点击可用领域进入业务界面；停用或缺失程序时进入相应管理路径。离开领域返回目录不改变内容。

## 数据范围

当前空间的领域登记与状态、本机兼容程序信息，不在目录复制领域业务数据模型。

## 前置能力

引用同级 [领域扩展注册](../领域扩展注册/领域扩展注册.md)、[领域启用状态管理](../领域启用状态管理/领域启用状态管理.md)和 [领域程序移除](../领域程序移除/领域程序移除.md)所维护的状态；具体业务引用对应领域子树。

## 边界情况与异常处理

[已确认] 单个领域运行失败不影响其他领域及管理目录；报错时保留已有数据，不自动停用整个空间。登记获取失败保留可确认的本机目录，明确无法取得最新状态，不伪装为空空间。

## 验收标准

可用、停用、缺失或不兼容程序的领域可区分；可用领域可进入，其他领域可找到管理入口；跨领域进入不复制数据；单个领域失败不让其他领域消失。
