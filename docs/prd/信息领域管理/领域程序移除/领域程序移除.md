# 领域程序移除 [C]

状态：原子节点及以下具体规则已于 2026-10-25 经用户确认。

实现状态（2026-10-25）：N09 已实现仅移除本机自定义程序，保留登记、启用状态与数据；明确确认并处理未保存输入。补齐原兼容包后接续旧内容；内置待办不单独移除。

## 功能描述

移除当前设备的自定义领域程序，保留工作空间登记、已有内容与可恢复材料。

## 定位

```text
信息领域管理
└── 领域程序移除 [C] ●
```

## 业务规则与约束

- [已确认] 移除只改变当前设备程序状态，不全空间删除领域登记、不删除内容，也不自动移除其他设备程序。
- [已确认] 执行前明确说明本机作用范围及数据保留；有未保存输入时先保存或明确放弃，取消则不移除，不静默丢失输入。
- [已确认] 移除成功后关闭本机相关业务入口，目录仍展示领域及程序待补齐状态；不把它伪装成空数据领域。
- [已确认] 领域数据、未同步操作及冲突材料仍可导出恢复；无法处理的维护动作保留待处理状态，不丢材料或阻塞其他领域。
- [已确认] 以后通过注册路径补齐同身份兼容程序，可接续原数据，不重建领域。内置程序能否独立移除由其具体领域定义。

## 交互流程和细节

用户选择移除本机程序 → 查看范围及数据保留说明 → 处理未保存输入 → 明确移除 → 更新本机程序状态；失败保留实际状态并反馈。管理目录和数据导出仍可使用。

## 数据范围

本机自定义领域程序及其可用状态；不改变空间共享的领域启用开关，不提供永久清空领域数据功能。

## 前置能力

引用同级 [领域扩展注册](../领域扩展注册/领域扩展注册.md)的稳定身份及本机程序信息，复用既有数据保存和导出恢复含义。不要求先全空间停用才可移除单设备程序。

## 边界情况与异常处理

[已确认] 程序移除失败不虚报完成；重新进入时核对实际可用状态。单设备移除不触发其他设备业务状态变化；补齐不兼容程序时沿注册校验拒绝静默覆盖。

## 验收标准

只移除本机程序，登记与数据保留；其他设备不被自动卸载或停用；未保存输入受到明确处理；缺失期间仍可导出；补齐兼容程序后接续原内容。
