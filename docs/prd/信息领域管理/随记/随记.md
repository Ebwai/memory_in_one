# 随记 [C]

状态：2026-11-01 已实现，验证独立入口、逐条记录、修改、删除、列表及重启找回。

## 功能描述

完全独立的插件域，允许用户逐条记录随时想到的点。

## 定位

信息领域管理 → 随记。

## 业务规则与约束

随记完全独立，不依赖或要求关联项目。随记只保留一个固定入口，所有随记集中记录在其中，不按模板创建多个随记插件。

已确认：随记支持逐条添加、修改、删除，并以列表回看。

已确认：随记采用纯文本，新添加的记录排在最前；删除单条记录前提示确认，取消则保留记录。保存与同步复用现有公共能力。

## 交互流程和细节

用户从固定随记入口进入，输入文本并保存；本机保存成功后清空输入并更新列表。通过列表编辑或删除记录，删除须确认。失败保留输入，未保存输入沿现有退出保护处理。

## 数据范围

独立随记内容。

## 前置能力

复用信息领域管理、既有保存反馈、冲突保护与同步能力。

## 边界情况与异常处理

删除前提示确认；取消则保留原内容。保存与同步反馈复用现有公共能力，不虚报成功。
