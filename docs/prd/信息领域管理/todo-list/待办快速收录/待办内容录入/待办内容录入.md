# 待办内容录入 [C]

状态：原子节点及以下具体规则已于 2026-10-24 经用户确认。

实现状态（2026-10-25）：N11 已实现文字唯一必填、中文与原文粘贴、空白拒绝及同文主动重复；不新增日期识别、拆分或长度限制。

## 功能描述

让用户以最少填写量准备一条待办，不在记录时强迫整理信息。

## 定位

```text
待办快速收录
└── 待办内容录入 [C] ●
```

## 业务规则与约束

- 已知要求：截止日期等属性均非必填。
- [已确认] 任务内容是唯一必填项，支持中文及普通文本粘贴。
- [已确认] 仅空白内容不能创建任务；判断时忽略首尾空白，其他文字保留。
- [已确认] 快速输入区域承载一条任务；一次提交创建一条任务，不自动将粘贴内容拆成多条，也不自动识别日期或完成标记。
- [已确认] 快速新增时无需进入属性设置；属性后续通过“待办推进”补充。

## 交互流程和细节

前置条件：用户已进入待办输入区域。

1. 用户输入或粘贴任务内容，可在提交前继续修改。
2. 提交空白内容时，显示需填写任务内容的提示并保留输入焦点。
3. 内容有效时交给“待办提交与结果反馈”处理。

具体长度限制不在本轮擅自设定；后续若存在限制，应明确向用户展示。

## 数据范围

当前尚未提交的待办文字，不默认附加日期、优先级、提醒或其他用户未填写的属性。

## 前置能力

无必须由本节点重复定义的前置能力；Windows 路径使用同级悬浮入口。

## 边界情况与异常处理

[已确认] 不因与已有任务文字相同而禁止输入；是否提交由用户决定。空白校验不创建任务，也不丢弃输入。应用退出或崩溃后的草稿恢复待另行确认。

## 验收标准

只输入中文任务内容即可进入提交；不填日期等属性不阻止提交；纯空白不能创建；相同文字可以作为用户主动创建的另一条任务。
