# 完成看板

- **功能描述**：为周报回看所选日期范围内完成的待办，保留目标上下文。
- **定位**：todo-list → 完成看板（原子能力）。
- **业务规则与约束**：本地日历日包含起止两天，依据有效实际完成时间；仅当前已完成且时间命中的事项计入完成数。递归带上祖先，无关兄弟不展示，祖先若未命中则标记“上下文”。缺失或无效完成时间不计入。
- **交互流程**：点击列表右侧“看板”，选择起止日期；默认最近七天，自动筛选，保留父子缩进和完成日期；点击“返回列表”退出。
- **数据范围**：当前工作空间本机可见、未删除的主待办；不声称覆盖未同步设备。
- **前置能力**：待办主界面回看、待办层级回看、待办完成状态切换。
- **边界情况与异常处理**：反向日期要求纠正；无匹配显示空状态；未完成父项仍显示但不计数；不执行写入。
