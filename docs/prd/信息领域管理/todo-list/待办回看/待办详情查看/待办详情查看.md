# 待办详情查看 [C]

状态：原子节点及以下具体规则已于 2026-10-25 经用户确认。

实现状态（2026-10-25）：N17 已实现按原任务身份读取、未完成及已完成详情、完整原文、明确未设置日期、读取失败保留及任务消失提示；关闭保留列表位置和展开状态，不产生写操作。

## 功能描述

查看单条任务的完整内容和当前信息，为继续处理提供上下文。

## 定位

```text
待办回看
└── 待办详情查看 [C] ●
```

## 业务规则与约束

- [已确认] 点击未完成区或已完成区的任务文字均可打开详情。
- [已确认] 显示完整任务内容、完成状态及可选截止日期；无截止日期明确呈现为未设置。
- [已确认] 详情代表原任务，不复制成一条新任务；仅打开和关闭详情不改变内容或状态。
- [已确认] 详情内可衔接待办推进的编辑、完成和删除操作，但这些写操作规则不在本节点重复定义。

## 交互流程和细节

前置条件：列表中存在一条可查看的任务。

1. 用户点击任务文字，看到其完整内容及当前信息。
2. 长内容可完整阅读；用户可进入已有的后续操作，或直接关闭详情返回列表。
3. [已确认] 关闭后保留原列表的滚动位置及已完成区展开状态，避免再次寻找同一位置。

## 数据范围

被选中的同一条任务，不新增备注、项目关联、历史版本或其他未确认字段。

## 前置能力

共享机制引用：[统一进度保障](../../../../公共机制/统一进度保障/统一进度保障.md)。其产品规则已确认，技术方案及实现尚未开始；待办复用它，不在领域内重复定义。

引用“统一进度保障”所提供的已有任务；查看入口由“待办主界面回看”提供；写操作交由“待办推进”。

## 边界情况与异常处理

[已确认] 打开期间发现任务已不存在时，明确提示并允许返回列表，不展示另一条任务来替代。无法获取最新信息时明确提示，既有可确认内容不伪装成最新；不因查看失败修改数据。

## 验收标准

未完成与已完成任务均可打开；长内容不丢失；未设置日期可识别；打开与关闭不会创建或修改任务；关闭后返回原查看位置。
