# 待办目标层级组织 [C]

状态：2026-10-26 产品规则已确认；已实现，验证结果见 docs/交付验收.md 的递归待办章节。

## 功能描述

以父子结构表示大目标和细目标，通过拖动改变事项归属。

## 定位

```text
待办目标层级组织 [C]
├── [[待办归属调整/待办归属调整.md|待办归属调整]] [C]
├── [[待办层级回看/待办层级回看.md|待办层级回看]] [C]
└── [[父子完成约束/父子完成约束.md|父子完成约束]] [M]
```

本轮展开直接下一层；整体删除复用既有待办删除，不新建重复删除能力。

## 业务规则与约束

- [已确认] 将 A 拖到 B 条目中央，A 成为 B 的子待办，在 B 下方展示；移动已有 A，不复制新事项。
- [已确认] 可递归建立多级子待办，不设固定层数上限。
- [已确认] 所有子待办完成后，父待办才允许完成；此规则适用于每一层。
- [已确认] 子待办全部完成后由用户手动勾选父待办，不自动完成父待办。
- [已确认] 恢复子待办为未完成，或向已完成父事项移入未完成事项时，将受影响的已完成祖先一并恢复为未完成，并明确提示。
- [已确认] 一条事项仅有一个直接父事项；禁止拖入自身或自身后代。
- [已确认] 以选中事项为根的整棵子树作为移动或删除单位，包含全部层级、全部完成状态的后代；不遗漏折叠或当前不可见的后代。
- [已确认] 删除父事项前再次明确确认，提醒会连同全部子待办一起删除；取消则整棵子树保留。该规则替代先前“保留子事项并上移”的建议。

## 交互流程和细节

拖起事项 → 指向目标条目中央 → 显示成为子待办的提示 → 释放后在目标下方呈现层级。

[已确认] 用缩进及展开/折叠展示层级；提供明确的“移到顶层”拖放区域，允许解除父级归属，移动时仍携带全部后代。

## 数据范围

当前领域的父子归属、层级呈现及完成约束；不扩展为多父级依赖图。

## 前置能力

复用待办回看、待办完成状态切换、待办删除及统一进度保障；同级排序复用待办优先顺序调整。

## 边界情况与异常处理

删除范围已确认为整棵子树，不采用子事项上移。保存失败不能呈现为已整体成功；复用统一进度保障的失败、未知结果及冲突反馈。

[已确认] 未完成父事项下的已完成子事项保留在原树位置并显示勾选，整棵树在根事项完成后再进入已完成区；见待办层级回看。
