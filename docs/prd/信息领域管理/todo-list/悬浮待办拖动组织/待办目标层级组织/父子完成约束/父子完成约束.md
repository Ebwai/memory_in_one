# 父子完成约束 [M]

状态：2026-10-26 产品规则已确认；已实现，验证结果见 docs/交付验收.md 的递归待办章节。

## 功能描述

保障父事项完成状态与全部子待办的完成条件一致，递归应用于每一层。

## 定位

待办目标层级组织 → 父子完成约束。

## 业务规则与约束

- 有任何未完成子待办时，父事项不能完成，应说明原因。
- 所有子待办完成后，父事项允许由用户手动完成，不自动勾选。
- 恢复子待办为未完成时，受影响的已完成祖先一并恢复为未完成，并明确提示。
- 向已完成目标移入未完成事项时，同样恢复受影响的已完成祖先。
- 检查涵盖折叠及不可见后代，不能仅以当前可见列表判断。

## 交互流程和细节

用户勾选父事项 → 检查子事项完成条件 → 满足则完成，否则保持原状态并说明仍有子待办未完成。恢复子事项或改变归属时联动祖先状态。

## 数据范围

当前事项、子孙和受影响的祖先完成状态。

## 前置能力

复用待办完成状态切换与统一进度保障；被待办归属调整引用。

## 边界情况与异常处理

并发变化、离线及结果未知沿统一进度保障处理，不能只在界面限制而让其他写入口绕过完成条件；失败时不宣称全部联动成功。
