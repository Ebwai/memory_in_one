# 待办层级回看 [C]

状态：2026-10-26 产品规则已确认；已实现，验证结果见 docs/交付验收.md 的递归待办章节。

## 功能描述

以可展开、折叠的树形结构回看大目标与细目标。

## 定位

待办目标层级组织 → 待办层级回看。

## 业务规则与约束

- [已确认] 缩进显示父子关系，支持展开与折叠；层级不设固定上限。
- [已确认] 未完成父事项下，已完成子事项保留在原树位置并显示勾选，避免完成子事项后丢失目标上下文。
- [已确认] 按顶层根事项状态划分未完成区与已完成区；根事项完成后整棵树进入已完成区，仍可展开查看各级子事项。
- [已确认] 已完成区继续默认折叠，数量按已完成根事项计算，计数提示说明按顶层目标计数；展开后可查看全部后代。

## 交互流程和细节

打开列表 → 查看顶层目标 → 展开目标查看子事项 → 可逐层继续展开；点击文字仍可查看原事项详情。

## 数据范围

当前待办领域的全部可查看事项及其层级、完成状态和排序。

## 前置能力

复用待办主界面回看、待办详情查看和待办优先顺序调整。

## 边界情况与异常处理

折叠仅影响显示，不影响父子完成检查或整体移动、删除范围。父事项未完成时，已完成子事项保留在原树位置；根事项完成后整棵树进入已完成区。
