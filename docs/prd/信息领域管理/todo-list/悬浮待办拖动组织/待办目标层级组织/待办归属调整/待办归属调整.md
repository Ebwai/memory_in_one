# 待办归属调整 [C]

状态：2026-10-26 产品规则已确认；已实现，验证结果见 docs/交付验收.md 的递归待办章节。

## 功能描述

通过拖动将事项归属到另一个目标，或解除当前父级归属。

## 定位

待办目标层级组织 → 待办归属调整。

## 业务规则与约束

- 拖至目标条目中央成为其子事项；拖至“移到顶层”区域解除父级归属。
- 一条事项仅有一个直接父事项，禁止移入自身或任意后代。
- 移动选中事项及全部后代，保留内部层级和相对顺序；移动已有事项，不创建副本。
- 不设固定层数上限；展开、折叠状态不影响移动范围。
- 移入未完成事项导致已完成祖先不再满足完成条件时，复用父子完成约束恢复其状态并提示。

## 交互流程和细节

拖起事项 → 指向目标或顶层区域 → 明确显示归属提示 → 释放后整棵子树移动。取消不修改任务。

## 数据范围

当前领域内选中事项及全部后代、原归属和新归属。

## 前置能力

引用同级父子完成约束，以及待办优先顺序调整、统一进度保障。

## 边界情况与异常处理

非法落点不执行移动；失败或结果未知时不宣称整体成功，沿统一进度保障核对结果。
