# 待办优先顺序调整 [C]

状态：2026-10-26 产品规则已确认；已实现，验证结果见 docs/交付验收.md 的递归待办章节。

## 功能描述

拖动改变待办排列，以越靠前越优先表达处理顺序。

## 定位

悬浮待办拖动组织 → 待办优先顺序调整；暂不继续拆分。

## 业务规则与约束

- [已确认] 拖到事项之间调整顺序，显示排序落点提示。
- [已确认] 同级事项独立排序；拖动父事项时携带整棵子树，内部层级及相对顺序保持。
- [已确认] 新增事项默认置于当前顶层列表首位；已有手动顺序保留。

## 交互流程和细节

从列表拖起待办 → 指向事项之间 → 显示插入位置 → 释放后改变顺序。

## 数据范围

当前领域的待办排列；不增加独立的优先级等级字段。

## 前置能力

复用待办主界面回看及统一进度保障；跨父级归属由待办目标层级组织定义。

## 边界情况与异常处理

取消拖动不改变事项。保存失败不宣称成功，结果未知时保留原操作供核对，不另建重复移动；复用统一进度保障。层级与完成区的呈现由待办层级回看定义。
