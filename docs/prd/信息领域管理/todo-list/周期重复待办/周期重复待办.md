# 周期重复待办 [C]

## 功能描述与定位

todo-list → 周期重复待办 [C] ●。按自然周期重复，并在周期内按次数推进任务。

## 业务规则与约束

- 用户已确认按自然日历刷新：每天零点、每周一零点、每月一日零点。首次设置记录当前设备时区，后续跨设备与迁移沿用该时区。
- 每周期设置正整数目标次数；每完成一次加一，达到目标才进入已完成并记录本次达标时间。
- 新周期进度归零、状态恢复未完成，不累积漏掉的周期；软件关闭后重开也适用。
- 重复条目下方显示细分进度条，每完成一次点亮一段绿色，同时显示次数。
- 未设置重复的旧任务保持单次完成行为。调整周期或次数重新开始本周期；关闭重复保留当时完成状态；恢复未完成清零本周期次数。
- 沿用父子完成约束；子任务跨周期恢复未完成时，已完成祖先也恢复未完成。

## 交互流程和细节

任务详情 → 设置重复 → 选择不重复／每天／每周／每月及周期次数 → 保存。列表点击完成控件或详情点击完成一次，显示逐段进度；达标后进入完成区，新周期回到未完成区。

## 数据范围与前置能力

重复配置、周期标识、周期内计数及当前完成时间；引用既有可靠保存、同步、冲突处理与父子完成约束。该功能不包含系统通知提醒。

## 边界情况与异常处理

目标次数限制为 1–1000；无效配置拒绝且保留输入。离线仍可推进；并发进度有分歧时保留冲突材料，不擅自覆盖。周期变化不会制造批量待同步写入。
