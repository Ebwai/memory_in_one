# 待办内容修改 [C]

状态：原子节点及具体规则已于 2026-10-25 经用户确认；同日归入 todo-list。

实现状态（2026-10-25）：N21 已实现未完成及已完成任务编辑、取消、空白拒绝、成功后列表与详情一致及失败保留。其他属性不变，旧版本和删除后的编辑不会静默覆盖或转为新增。

## 功能描述

修改已有待办的文字，继续完善同一条任务，而不创建独立副本。

## 定位

```text
待办推进
└── 待办内容修改 [C] ●
```

## 业务规则与约束

- 用户已要求快速修改任务。
- [已确认] 未完成和已完成任务均可从详情进入内容编辑，默认带入原文字。
- [已确认] 保存前可取消；取消或关闭编辑时放弃本次未保存修改，保留原任务。
- [已确认] 内容不能改为空白，沿用待办内容录入的非空原则；不禁止与其他任务文字相同。
- [已确认] 修改内容不改变创建时间、截止日期和完成状态；已完成任务不会因改字自动恢复为未完成。
- [已确认] 保存期间保留当前编辑文字并暂停同一任务的其他写操作，成功后更新列表与详情，失败时保留文字供继续修改和重试。

## 交互流程和细节

前置条件：任务仍存在，当前无结果未明确的写操作。

1. 点击任务文字进入详情，选择编辑内容。
2. 调整文字，选择保存或取消。
3. 空白输入提示填写内容；成功时显示更新后的任务；失败时显示原因并保留编辑内容。

## 数据范围

仅当前任务文字，不产生新任务，不覆盖其他属性。

## 边界情况与异常处理

[已确认] 任务已被删除时明确提示，不能把修改自动变为新增。发现其他设备已修改时不静默覆盖，具体解决路径由统一进度保障细化。保存结果不明时保留输入并说明状态，不能把它当作确定失败后盲目覆盖重试。

## 验收标准

可编辑未完成与已完成任务；取消后原文不变；不能保存纯空白；成功后列表和详情一致；失败保留文字；其他属性与任务身份不改变。
