# 预设模板创建插件 [C]

状态：2026-11-01 已实现并验证模板创建、多实例、目录入口、重命名、整体删除及同步。

## 功能描述

用户按照系统提供的预设模板创建独立插件。

## 定位

信息领域管理 → 预设模板创建插件。可选模板包括 [[../项目模板/项目模板.md|项目模板]]。

## 业务规则与约束

- 同一项目模板可以创建多个独立插件，如“装修项目”“产品开发”。
- 每个插件各自管理内容，互不混用。
- 按项目模板创建的各个插件直接显示在现有插件域目录中，与 todo-list、随记并列；例如“装修项目”“产品开发”各自拥有独立入口。
- 项目插件支持重命名及整体删除。整体删除前必须提示将删除该插件内全部项目想法与待办，并由用户确认；取消则保留插件和全部内容。删除范围仅限所选项目插件。
- 当前不提供用户自定义模板；未来可能加入，尚非本期要求。
- 新建项目时选择“项目”模板并填写名称；名称不能为空，允许同名项目。同名插件仍各自独立，不按名称合并内容。
- 保存与同步复用现有公共能力。
- 模板创建与既有扩展程序注册是不同动作，不撤销既有注册能力。

## 交互流程和细节

用户在领域目录的“按模板新建插件”选择项目模板 → 填写项目名称 → 创建项目插件 → 新插件直接显示在目录中。创建成功后清空名称；失败保留输入。目录提供重命名与删除项目操作，整体删除明确确认全部想法与待办，取消保留内容。保存结果显示本机保存及待同步状态。

## 数据范围

模板与按模板创建的插件之间的产品归属；具体字段未定义。

## 前置能力

信息领域管理；创建结果需可在工作空间中访问，具体复用关系待细化。

## 边界情况与异常处理

整体删除须明确确认全部内容范围，不影响其他项目插件、todo-list 或随记。名称为空时不能创建并提示填写；允许同名。模板后续变化对已有插件的影响尚未定义，不属于本轮要求。
