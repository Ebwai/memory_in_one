# 领域扩展注册

状态：N07–N10 已实现，2026-10-25，覆盖登记、启停、本机程序移除及目录进入。同步、冲突和导出沿后续节点整合。

## 登记与本机程序分离

### 模块概览

承接 [扩展架构](../architecture/extensions.md) 和 PRD 领域扩展注册。实现锚点为 contracts/domains.ts、extension-sdk/validation/validate.ts、core/workspace/domains.ts、adapters/extension-loader/programs.ts。

### 契约和数据语义

首版单文件 JSON，使用 JSON Schema 2020-12 的封闭标量对象子集；字段、视图与动作均为数据，不执行脚本，不接受网络引用或跨领域能力。未知版本与关键字拒绝。格式与限制以校验器为事实源。

空间登记作为 system.domains 内的普通受保护记录，与待同步操作同事务保存；稳定领域身份作为记录键。设备程序另存设备专属目录，摘要是安装材料身份。读取同步来的登记不安装代码。后续同步和导出须按此区分，当前不宣称已联网同步。

### 流程及失败恢复

先校验与展示，再明确注册。核心比较已有登记；相同身份不同程序拒绝隐式升级。程序材料完整写入并刷新到临时文件后原子发布；包对象键规范排序，单纯调整键顺序不改变程序身份。缺失或损坏时可用相同原包修复，不能用不同版本冒充补齐。安装不可变程序材料后，以仅当登记不存在的条件提交空间登记和待同步。提交失败最多留下无登记引用的本机程序材料，不形成可进入的半登记领域；不修改已有登记或业务内容。重试查询原操作并复用登记。补齐程序只恢复完全相同的包，不写新的领域内容。

### 一致性与验证

SQLite 在写锁内比较预期序号，防止多个窗口或进程检查后覆盖竞争登记。原操作回执优先返回，不重放旧内容。注册不启用。验证真实磁盘重启、重复提交、竞争注册、缺程序补齐、同名隔离、权限和格式拒绝。

## 领域启用状态管理

启停只更新登记记录中的共享状态并同事务追加待同步材料；不删除领域内容、操作或程序。启用时复核本机程序摘要，缺失时拒绝。SQLite 预期序号保护竞争状态变更，不把旧读取覆盖为新状态。桌面在确认作用范围后调用；有草稿的业务视图须先保存、明确放弃或取消，不能仅卸载视图。实际同步与跨设备冲突在对应节点整合。

## 领域程序移除与目录进入

程序材料按摘要限制在当前设备、当前空间的目录。删除不改登记或启用状态；重复移除安全，失败不宣称完成。内置程序的可移除策略由宿主注入，核心不绑定待办身份。缺程序的领域仍留在管理目录，通过原扩展包补齐。

目录展示登记版本、稳定身份、共享开关和本机程序可用性。可进入领域的表单遵循其 schema 和视图声明，不借用待办字段；create、update、delete 只对领域已声明动作开放。核心签发限定空间与领域的存储能力，SQLite 在最终写锁内再次比较领域登记序号，避免校验后停用仍写入。移除在当前宿主请求边界串行执行。

桌面把草稿所有权保留在当前视图，跨视图、停用、程序移除及正常窗口关闭前先处理草稿；取消保持原输入。读取失败保留可展示目录和内容，不以空列表伪装成功。实现锚点：host/domain-features.ts、renderer/domains.tsx、renderer/domain-view.tsx。

验证锚点：tests/integration/domains.test.ts、tests/e2e/workbench.test.mjs；真实窗口覆盖注册、启用、保存草稿后停用、取消、程序移除及补齐后旧内容回现。
