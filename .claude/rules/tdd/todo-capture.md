# 待办快速收录

状态：N11–N15 已实现并整合，2026-10-25。本设计记录 Windows 本机快速收录；后续回看已在 [N16–N20 TDD](todo-review.md) 单独实现，推进已在 [N21–N25 TDD](todo-progression.md) 实现，联网同步及 MCP 仍待后续节点。

## 内容录入

承接 PRD 待办内容录入与 todo-list 内置映射；Architecture 位置为共享包 todo-list 及桌面 host/bridge/renderer。程序为内置独立包，默认映射由创建后的宿主组装提供，不让核心或用户扩展继承待办字段。

新建空间的本机副本预先登记并启用内置待办，登记与开关沿用可靠保存机制。接入已有空间不因缺少登记而凭空新增领域。已绑定且有兼容程序的启用待办由客户端默认进入；管理目录可停用，内置程序不单独卸载。

任务文字只以 trim 判断空白，保存原文本；不拆分多行粘贴，不识别日期或状态，没有新增长度限制。实现锚点为 packages/todo-list/src/index.ts、renderer/todo-capture.tsx。

## Windows 悬浮收录入口

已绑定且待办可用时，启动默认显示输入区域，使用同一个 BrowserWindow 切换悬浮和管理模式。同一窗口保留同一本机应用服务和副本。窗口保留系统标题栏拖动；悬浮模式默认置顶，可由受限桥接切换置顶。窗口展示变更不提交或清除输入。管理模式取消置顶，停用后不再打开业务入口。

正常关闭窗口由主进程发起草稿检查，renderer 确认保存、明确放弃或取消；只有允许退出后才关闭。强制进程终止及未提交草稿的崩溃恢复不作为当前承诺。程序退出时停止本机服务。

## 待办提交与结果反馈

按钮与非输入法选词状态下的 Enter 进入同一提交函数；Shift+Enter 换行。同步引用锁在 await 前设定，React 状态尚未渲染前的连续事件也不能重复受理。提交期间输入只读，操作身份、任务身份、原文字与创建时间构成固定请求快照。

宿主固定 todo-list 领域，调用其 prepareTodo，不接受调用方更换空间或领域。核心领域存储能力在最终事务复核启用状态，并只允许新增不存在的任务；原操作回执仍可幂等返回。初始未完成，不添加未填写属性。

本机事务成功后才清空文字、保留焦点并展示成果；网络未调用，不将成果描述为已同步。已知失败保留可编辑文字；响应不明保持原文字和身份，禁止改为新操作，先核对回执，缺回执时沿相同操作身份重新提交。核对已有成果可在停用后进行，但新写入须再次通过领域门禁。结果未确认时不能通过放弃草稿绕开保护。
