# 管理控制中心与空间目录

## 模块概览

关联 PRD：管理控制中心与多空间。renderer/workspace.tsx 拥有当前管理页与空间卡片投影；domains.tsx 维护领域草稿门禁与工作台返回。宿主继续拥有绑定、凭据与磁盘副本。

## API 与数据模型

workspace:spaces 接受 list/switch；只向 renderer 返回 WorkspaceBinding，不返回 PrivateBinding.secret。spaces.json 原子保存设备侧 PrivateBinding 目录，旧 binding.json 自动并入，继续用系统加密保存服务器凭据。binding.json 代表当前空间；副本和扩展程序按 workspaceId 隔离。

## 关键流程

切换：领域草稿门禁 → 宿主 busy 门禁 → 暂停同步调度并等待运行中同步结束 → 准备所选本机服务地址 → 原子更新当前绑定 → 重置同步投影和恢复标志 → 恢复调度。renderer 按空间身份重新挂载内容与管理组件，防止上一空间结果进入新空间。

接入其他空间必须显式 additional，普通重新核验仍要求原身份一致；额外空间使用独立副本路径。创建和确认接入时暂停同步，完成后恢复。

导出预览与最终导出前均核对同步结果；未完成同步、结果待核对或冲突时拒绝走统一位置完整备份。最终快照仍由现有宿主完整身份核对及原子交付承接。恢复沿原空白目录、预览确认与迁移启用流程，服务器直接恢复未实现。

## 状态与异常

暂停期间不触发其他同步；切换失败保留原绑定并恢复调度。空间目录不清理旧副本和待同步材料。服务器拓扑为静态未实现占位，不推断设备在线事实。

## 验证

tests/e2e/management-pages.test.mjs 覆盖四页独立显示、两个本机空间创建/切换、内容隔离与重启选择恢复；既有持久化、同步与恢复测试提供底层行为验证。
